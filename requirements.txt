# NOTE: flash-attn is intentionally NOT pinned here as a wheel.
# The download.pytorch.org torch 2.6 wheel uses the OLD C++ ABI
# (_GLIBCXX_USE_CXX11_ABI=0), but flash-attn's prebuilt "cxx11abiFALSE" wheels
# for torch 2.6 are actually compiled abiTRUE -> they fail to import with
# "undefined symbol: _ZN3c105Error...__cxx11...". Build it from source AFTER
# installing this file so it matches the installed torch ABI exactly:
#
#   pip install ninja packaging
#   MAX_JOBS=8 TORCH_CUDA_ARCH_LIST="8.9" FLASH_ATTENTION_FORCE_BUILD=TRUE \
#       pip install flash-attn==2.8.3 --no-build-isolation
#
# - TORCH_CUDA_ARCH_LIST = your GPU's compute capability: L40S/4090=8.9,
#   A100=8.0, H100=9.0 — avoids building every architecture.
# - Keep MAX_JOBS LOW: each CUDA compile unit needs ~10-16 GB RAM. MAX_JOBS=8
#   peaks ~130 GB. Too high -> the build gets OOM-killed ("Killed" in the log).
#   Rule of thumb: MAX_JOBS = available_RAM_GB / 16.
